# News Preferences

The LLM reads this on every run to score and filter news items.
Edit freely — changes take effect on the next `/ai-news` run.

---

## I love this (score high, always include)

- **Claude / Anthropic** — model releases, Claude Code updates, API changes, anything from Anthropic
- **AI coding assistants & CLI agents** — Claude Code, Cursor, Aider, Cline, Copilot, Devin, any tool that helps developers write or run code
- **LangChain & LangGraph** — releases, new features, tutorials, migration guides
- **AI agents & automation** — autonomous agents, multi-agent systems, agentic workflows, real-world use cases
- **Prompt engineering & context management** — techniques, patterns, new research on getting better outputs
- **Open-source LLM tooling** — Ollama, llama.cpp, vLLM, anything self-hostable or developer-facing
- **Python AI/LLM frameworks** — LangChain, LangGraph, LlamaIndex, CrewAI, AutoGen, smolagents, Haystack, DSPy, and anything similar
- **LLM news in general** — new models, capabilities, benchmarks, API updates from any major lab (OpenAI, Google DeepMind, Mistral, Meta, xAI, etc.)

## I like this (include if it's good)

- **Industry news** — funding rounds, acquisitions, product launches with real developer impact
- **AI research** — papers on agents, reasoning, evals, context length — practical stuff, not pure academia
- **Developer tooling** — anything that meaningfully speeds up a Python or AI developer's workflow
- **YouTube creators I follow** — always include recent videos from channels in the list below

## Skip this (filter out, score very low)

- Crypto, blockchain, NFT, Web3
- AI image, video, audio, music, or art generation tools (Midjourney, Sora, ElevenLabs, etc.)
- Consumer hardware — phones, laptops, wearables, AR/VR
- Self-driving cars and robotics (unless the story is really about LLM agents)
- Enterprise SaaS AI announcements (Salesforce, SAP, ServiceNow, etc.)
- AI in healthcare, education, legal, finance — unless it's about the underlying models or dev tooling
- Vague opinion pieces and hot takes with no technical substance
- Social media drama
- AI safety / ethics / policy debates (unless they directly affect API access or developer tools)
- Job listings, layoffs, or hiring news
- Gaming news
- Marketing fluff — press releases, landing pages, no technical content
- Tutorials aimed at non-developers (ChatGPT tips for general users, no-code tools)

## Scoring boosts

Apply a +0.1 bonus if any of these are true:

- Includes a GitHub repo, code release, or hands-on tutorial
- Breaking announcement about a model or tool I use daily
- YouTube video from a channel I follow
- Direct comparison or benchmark between tools I care about

## Scoring penalties

Apply a -0.1 penalty if any of these are true:

- Clickbait or vague title ("AI will change everything", "The future of X")
- Paid product announcement with no technical depth
